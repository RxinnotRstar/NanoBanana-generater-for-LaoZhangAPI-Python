# Gemini AI（Nano banana）图像生成器 - 老张API专版

一款基于 tkinter 的应用程序，通过 Nano Banana API （老张API）调用 Google Gemini 模型生成图像。支持参考图上传、多分辨率选择和实时界面缩放。使用 Kimi AI 编写代码。

我的邀请链接：https://api.laozhang.ai/register/?aff_code=EVOV

## 主要特性

- **双模型支持**：`Gemini 2.5 Flash Image` (稳定版) 和 `Gemini 3 Pro Image Preview` (最新版)
- **多分辨率输出**：`1K`、`2K`、`4K` (仅限 `Gemini 3`，`Gemini 2.5` 仅支持`1K`)
- **参考图功能**：最多支持 14 张参考图片，单张 ≤10MB
- **智能纵横比**：支持 `21:9`、`16:9`、`4:3`、`1:1`、`9:16` 等 9 种比例
- **实时预览**：生成图片自适应窗口大小，无裁剪显示
- **原始数据查看**：支持查看和保存完整 API 响应（不含 Base64 数据）
- **智能日志**：可选的 JSON 格式日志记录，分类保存（success/error/save）
- **界面缩放**：`75%-500%` 手动缩放
- **网络超时**：可配置超时时间（0 表示无限制）
- **自动依赖检测**：启动时自动检查并提示安装缺失的依赖包

## 系统要求

- Python 3.7+
- Windows 10/11（推荐）、Linux、macOS
- 网络连接（需访问 `api.laozhang.ai`）

## 使用方法

### 基本生成流程

1. **填写提示词**：在提示词文本框中输入描述（最多 2000 字符，实时显示字数统计）
2. **选择模型**：Gemini 3 Pro 支持更高分辨率和更多纵横比
3. **设置参数**：
   - 纵横比：21:9、16:9、4:3、3:2、1:1、9:16、3:4、2:3、5:4、4:5
   - 分辨率：根据模型自动切换（Gemini 2.5 仅支持 1K，Gemini 3 支持 1K/2K/4K）
4. **添加参考图**（可选）：
   - 点击"添加图片"选择最多 14 张参考图（支持 JPG、PNG、WebP）
   - 点击图片右上角 × 删除单张
   - 点击"清空全部"一键清除所有参考图
5. **生成图片**：点击"生成图片"按钮（网络超时 0 表示无限制，默认 1200 秒）
6. **保存结果**：
   - 点击"保存图片"导出 PNG（自动生成带时间戳和模型信息的文件名）
   - 点击"保存原始JSON"导出完整响应（自动压缩 Base64 图像数据）
   - 点击"复制图片"将图像复制到系统剪贴板

### 日志功能

启用"保存日志到文件"后，所有操作会记录在 `logs/` 目录：

- **成功日志**：`gemini_YYYYMMDD_HHMMSS_success.log`（包含完整请求和响应）
- **错误日志**：`gemini_YYYYMMDD_HHMMSS_error.log`（包含错误信息和原始响应）
- **保存日志**：`gemini_YYYYMMDD_HHMMSS_save.log`（记录保存的文件路径）

日志采用 JSON 格式，包含时间戳、模型、提示词、参数、响应数据等完整信息。

## 注意事项

⚠️ **重要提示**

- 生成失败时，请检查"原始响应"标签页中的 `finishReason` 和 `safetyRatings` 信息
- 大分辨率图片（2K/4K）生成时间较长，建议设置充足的超时时间，否则脚本会提前结束等待并报错
- 日志文件可能包含 API 密钥和提示词，请妥善保管 `logs/` 目录
- 缩放功能会修改主窗口大小，在最大化状态下切换缩放可能会暂时恢复普通窗口
- 参考图总大小会影响请求速度和成功率，建议控制图片数量和尺寸

## 故障排除

**图片生成失败**

1. 检查 API 密钥是否有效
2. 确认提示词未触发安全过滤器（查看 `safetyRatings`）
3. 查看"原始响应"标签页的 `finishReason` 错误信息
4. 尝试切换回稳定版模型（Gemini 2.5 Flash）
5. 检查网络超时设置是否过短

**界面显示异常**

1. 重置缩放至 100%
2. 检查系统 DPI 设置
3. 确保所有依赖已正确安装（`requests` 和 `Pillow`）
4. 尝试重启程序恢复默认状态

**无法复制图片**

- Windows：确保系统支持 BMP 格式剪贴板
- macOS：使用 `osascript` 命令复制（无需额外依赖）
- Linux：需安装 `xclip` 或 `wl-copy`（Wayland）
- 如果失败，可手动保存图片后使用系统工具复制

**依赖安装失败**

- Windows：使用 `pip install --user` 安装到用户目录
- Linux/macOS：使用 `pip3 install --user` 安装到用户目录
- 如自动安装失败，请手动运行提示的安装命令
