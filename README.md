# 老张API - NanoBanana 和 GPTimage2 图片生成器

一款基于 tkinter 的应用程序，通过老张 API 调用 Google Gemini 及 GPT Image 2 等模型生成图像。支持多项实用功能。

> _老张API用户开箱即用，无需修改源码。非老张API用户，可以基于中转站提供的API文档，用AI改成你的中转站的版本。_

_脚本源码使用 Kimi AI 和 Deepseek 生成，开发者负责编写代码以外的一切事务。_

我的邀请链接：https://api.laozhang.ai/register/?aff_code=EVOV

## 主要特性

- **多模型支持**：`Gemini 2.5 Flash Image`、`Gemini 3 Pro Image Preview`、`Gemini 3.1 Flash Image Preview`、`GPT Image 2`
- **多分辨率输出**：1K、2K、4K（`Gemini 2.5 Flash Image` 仅支持 1K）
- **上传参考图片**：Gemini 系列最多 14 张，GPTimage2 暂定最多 10 张
- **实时预览**：生成图片后自动解码并展示
- **原始数据查看**：查看和保存 API 响应数据
- **界面缩放**：75% - 500% 手动缩放
- **网络超时**：可灵活配置超时时间（0 表示无限制，默认 1200 秒）
- **创新型参数校验**：通过"抽查参数"的方式，减少用户忘记复核配置导致浪费额度的几率
- **自动依赖检测**：启动时自动检查并提示安装缺失的依赖包
- **日志记录**：支持开启自动保存请求/响应日志功能，内附简易图片提取工具
- **代理检测**：检测到用户开启系统代理时主动提示，避免传输失败
- **导入配置文件**：可以导入 `.toml` 配置文件实现一键配置，支持启动时自动导入
- **文件选择器**：自动加载同目录下的增强文件选择器，提供更美观的文件浏览体验(需下载仓库内的文件选择器脚本，且不能更改文件名)
- **防误关保护**：关闭窗口时根据状态弹出随机确认或滑块验证，防止误关
- **任务栏进度条**：生成图片时 Windows 任务栏显示进度状态（需安装 `comtypes`）
## 系统要求

- 至少 Python 3.7，推荐 Python 3.11+
- Windows 10/11（推荐）、Linux（仅测试过 Debian）、macOS（缺乏设备进行测试，欢迎反馈 Linux 和 macOS 的 BUG）
- 网络连接（用于生成图片和自动安装依赖）

# 如自动安装失败，手动安装依赖

## TOML 配置文件

配置文件采用 `.toml` 格式，支持一键填写所有配置项，无需逐一手动填写。

### 使用方式

**方式一：自动导入（推荐）**

将配置文件命名为 `default.toml`，放在脚本同目录下，启动时自动导入，不会弹出确认弹窗。

**方式二：拖入导入**

直接将 `.toml` 文件拖入程序窗口即可触发导入。

### 快速上手

复制下面内容，保存为 `配置.toml`，按需修改，拖入窗口即可（详细文件已经内嵌在代码里面）：

```toml
import_mode = "overwrite_existing"

[api]
key_laozhang = "sk-这里换成你的密钥"
model_laozhang = "gemini-3.1-flash-image-preview"

[generation]
aspect_ratio = "4:3"
resolution = "2K"
network_timeout = 1800
confirm_before_generate = true
log_to_file = false

prompt = '''
生成一只猫，要求：
1. 橘色上肢，紫色下肢；
2. 正在玩CSGO。
3. 电脑桌面上有一盆猫粮。'''

[ui]
zoom = "125%"
prompt_lines = 4
```

不想填的项目删掉即可，不要留空值。

### 导入模式

#### `clear_and_overwrite`（清空并覆盖）

- 清空程序当前的全部内容（包括提示词、参考图片等）
- 然后将配置文件里的内容填进去
- **没写的配置项会被还原成默认值**
- **写了但留空的配置项会被清空**
- 存在无法解析的值时，弹窗报错，**拒绝导入全部内容**

适用场景：希望完全使用一套新配置。

#### `overwrite_existing`（覆盖已有）— **推荐**

- 保留程序当前的所有设置
- 只覆盖配置文件里**写了的**配置项
- **没写的配置项不变**
- **写了但留空的配置项会被清空**
- 存在无法解析的值时，弹窗报错并**询问是否继续导入剩下的正确项**

适用场景：只更新部分配置（如更换 API 密钥、改提示词），不影响其他设置。

### 配置项说明

#### `import_mode` — 导入模式（必填）

```toml
import_mode = "overwrite_existing"
```

可选值：`"clear_and_overwrite"`（清空并覆盖）、`"overwrite_existing"`（覆盖已有）

#### `[api]` — API 设置

```toml
[api]
key_laozhang = "sk-..."
model_laozhang = "gemini-3.1-flash-image-preview"
```

- **`key_laozhang`**：API 密钥。留空则不清除已有密钥（`overwrite_existing` 模式下）。旧版字段 `key` 已弃用，脚本自动检测并弹窗提示迁移。
- **`model_laozhang`**：模型选择。可选值：`"gemini-2.5-flash-image"`, `"gemini-3-pro-image-preview"`, `"gemini-3.1-flash-image-preview"`, `"gpt-image-2-vip"`。旧版字段 `model` 已弃用。

#### `[generation]` — 生成参数

```toml
[generation]
aspect_ratio = "4:3"
resolution = "2K"
network_timeout = 1800
confirm_before_generate = false
log_to_file = false
```

- **`aspect_ratio`**：输出图片纵横比。可选值：竖版 `"16:9"`, `"5:4"`, `"4:3"`, `"3:2"`；特殊 `"1:1"`, `"21:9"`；横版 `"2:3"`, `"3:4"`, `"4:5"`, `"9:16"`。
- **`resolution`**：分辨率。可选值 `"1K"`, `"2K"`, `"4K"`。注意 `gemini-2.5-flash-image` 仅支持 `"1K"`。
- **`network_timeout`**：网络超时时间，单位秒。`0` 表示无限制，默认 `1200`。
- **`confirm_before_generate`**：生成前是否弹出参数确认弹窗。`true` 或 `false`。
- **`log_to_file`**：是否自动保存生成日志。`true` 或 `false`。

#### `prompt` — 提示词

```toml
prompt = '''
这里写提示词，
可以换行。
'''
```

支持多行提示词，用三个单引号 `'''` 包裹。忘记加结束的三个单引号会导致文件无法解析。

#### `[ui]` — 界面设置

```toml
[ui]
zoom = "125%"
prompt_lines = 4
```

- **`zoom`**：界面缩放比例。可选值：`"75%"`, `"100%"`, `"125%"`, `"150%"`, `"175%"`, `"200%"`, `"250%"`, `"300%"`, `"500%"`。
- **`prompt_lines`**：提示词输入框行数，范围 2~98。

#### `[[reference_images]]` — 参考图片路径

```toml
[[reference_images]]
path = "D:/素材图片/参考图1.png"

[[reference_images]]
path = "D:/素材图片/参考图2.jpg"
```

每条 `[[reference_images]]` 对应一张参考图片。

- 支持绝对路径和相对路径（相对于脚本目录，不推荐小白使用）
- 建议使用正斜杠 `/`；若用反斜杠 `\` 需双写转义
- 图片格式仅限 `.jpg`, `.jpeg`, `.png`, `.webp`
- 文件必须真实存在且为有效图片，否则导入时报错
- 留空或直接用 `#` 注释掉整段即可跳过

### 编辑注意事项

- **不想改动的配置项直接删掉那行**，程序不会动它（`overwrite_existing` 模式下）
- **写了但留空的配置项会被清空**，不想被改动就整行删掉，不要留空值
- 路径格式推荐用正斜杠 `/`，避免反斜杠转义问题
- 文件保存时使用 UTF-8 编码，避免中文乱码

### 典型场景

**切换工作配置**：保存多份不同用途的 `.toml` 文件（如「二次元风格.toml」「写实风格.toml」），用到哪个拖哪个。

**开箱即用**：用 `clear_and_overwrite` 模式写一份基础配置，留空 API 密钥，与脚本一起发给别人。

**固定工作流**：命名 `default.toml` 放在脚本同目录，每次启动自动加载。

## 使用方法

### 基本生成流程

1. **填写提示词**：在提示词文本框中输入描述（最多 2000 字符，实时显示字数统计）
2. **选择模型**：不同模型支持的分辨率和参考图数量不同
3. **设置参数**：
   - 纵横比：1:1、2:3、3:2、3:4、4:3、4:5、5:4、9:16、16:9、21:9
   - 分辨率：根据模型自动切换可用选项
4. **添加参考图**（可选）：
   - 点击"添加图片"选择参考图（如安装了增强文件选择器，会使用更美观的界面）
   - 点击图片右上角 × 删除单张
   - 点击"清空全部"一键清除
   - 也可以直接将图片文件拖入窗口
5. **生成图片**：点击"生成图片"按钮
6. **保存结果**：
   - 点击"保存图片"导出（自动生成带时间戳和模型信息的文件名）
   - 点击"保存原始JSON"导出完整响应
   - 点击"复制图片"复制到系统剪贴板

### 生成前参数确认

该功能默认开启，每次生成前会随机抽查模型、纵横比、分辨率参数之一，需要选择正确选项才能继续，否则会拒绝生成，并提醒你修改参数。如果这些参数没有更改过，那么弹窗不会出现，减少打扰，直到参数被更改。

- 该功能可以在"生成图片"按钮上方的"**生成前确认**"复选框处关闭。

### 日志功能

启用"保存日志到文件"后，所有操作会记录在 `logs/` 目录：

- **日志命名规则**：按模型区分（如 `Gemini-3.1_20260510_143022_success.log` 或 `GPT-image-2_20260510_143022_error.log`）
- **日志内容**：JSON 格式，包含时间戳、模型、提示词、参数、响应数据等完整信息
- **图片提取工具**：启用日志时自动生成 `export_images_from_log（从Log中提取图片）.py`，双击运行可从日志文件中提取并保存图片
- **安全保护**：API Key 在日志中已自动脱敏为 `SK_HIDDEN_API_KEY`

### 关闭保护

脚本提供多层关闭保护，防止误操作：

- **无内容时**：直接关闭，无干扰
- **有提示词或参考图时**：随机弹出四按钮确认弹窗（1 个"确定"+ 3 个"取消"，按钮位置随机），连续选错 3 次会锁定为保底弹窗
- **图片生成中**：弹出滑块验证弹窗，需要滑动到指定数值才能关闭，连续失败 3 次同样保底

## 注意事项

⚠️ **重要提示**

- 大分辨率图片（2K/4K）生成时间较长，建议设置充足的超时时间
- GPT Image 2 VIP 模型的参考图虽然设置了上限为 10 张，但实际上超过 5 张可能会导致模型忽略部分图片
- 日志文件可能包含提示词内容，请妥善保管 `logs/` 目录
- 缩放功能在最大化状态下切换，可能会暂时恢复普通窗口
- 参考图总大小会影响请求速度和成功率，建议控制图片数量和尺寸
- macOS/Linux 平台复制图片功能需依赖系统命令（`osascript` / `xclip` / `wl-copy`），如无法复制请检查相应工具是否安装
- 生成失败时，请检查"原始响应"标签页中的 `finishReason` 和 `safetyRatings` 信息，或留意弹窗

## 故障排除

**图片生成失败**

1. 检查 API 密钥是否正确，是否余额耗尽
2. 确认提示词未触发安全过滤器（查看 `safetyRatings` 或者弹窗）
3. 查看"原始响应"标签页的 `finishReason` 错误信息
4. 尝试切换其他模型生成
5. 检查网络超时设置是否过短
6. 如开启系统代理，请确认网络稳定或关闭代理重试

**界面显示异常**

1. 重置缩放至 100%
2. 用鼠标拖动调整粉色的分隔条
3. 确保所有依赖已正确安装
4. 重启程序恢复默认状态

**无法复制图片**

- Windows：确保 `pywin32` 已安装（`pip install pywin32`），否则仅支持 BMP 格式
- macOS：需要系统支持 `osascript` 命令
- Linux：X11 需要 `xclip`，Wayland 需要 `wl-copy`
- 如仍失败，可手动保存图片后在系统内复制

**依赖安装失败**

- Windows：使用 `pip install --user` 安装到用户目录
- Linux/macOS：使用 `pip3 install --user` 安装，或视情况选择正确的安装方法
- 检查 Python 环境是否正常，`pip` 是否已添加到系统变量（未添加 `pip` 会导致无法自动安装依赖，推荐重装 python）
