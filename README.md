# 老张API - NanoBanana 和 GPTimage2 图片生成器

一款基于 tkinter 的应用程序，通过老张 API 调用 Google Gemini 及 GPT Image 2 等模型生成图像。支持多项实用功能。

> _**老张API用户开箱即用，无需修改源码。非老张API用户，可以基于中转站提供的API文档，用AI改成你的中转站的版本。**_

*脚本源码使用 Kimi AI 和 Deepseek 生成，开发者负责编写代码以外的一切事务。*

## 主要特性

- **多模型支持**：`Gemini 2.5 Flash Image`、`Gemini 3 Pro Image Preview`、`Gemini 3.1 Flash Image Preview`、`GPT Image 2`
- **多分辨率输出**：1K、2K、4K（`Gemini 2.5 Flash Image` 仅支持 1K）
- **上传参考图片**：Gemini 系列官方最多 14 张，GPT VIP 暂定最多 10 张
- **实时预览**：生成图片后自动解码并展示
- **原始数据查看**：查看和保存 API 响应数据
- **界面缩放**：75% - 500% 手动缩放
- **网络超时**：可灵活配置超时时间（0 表示无限制，默认 1200 秒）
- **创新型参数校验**：通过“抽查参数”的方式，减少用户忘记复核配置导致浪费额度的几率
- **自动依赖检测**：启动时自动检查并提示安装缺失的依赖包
- **日志记录**：支持开启自动保存请求/响应日志功能，附赠简易图片提取工具
- **代理检测**：检测到用户开启系统代理时主动提示，避免传输失败

## 系统要求

- Python 3.7+
- Windows 10/11（推荐）、Linux、macOS（缺乏设备进行测试，欢迎反馈这两个系统下的BUG）
- 网络连接（用于生成图片和自动安装依赖）

## 安装步骤

```bash
# 直接运行脚本，自动检测依赖
python 老张API-NanoBanana调用器.py

# 如自动安装失败，手动安装依赖
pip install requests pillow

# Windows 用户可选的安装（增强剪贴板功能）
pip install pywin32
```

脚本启动时会自动检查 `requests` 和 `Pillow` 依赖，并提示安装缺失的包。

部分依赖不安装仍可进入GUI，但可能导致部分功能缺失。

1. 获取 API 密钥：访问老张 API 平台注册账号（仅支持Gmail邮箱注册，或者使用Github登录），并充值或直接使用体验余额

2. 配置令牌：
   - 点击“令牌”，找到默认令牌，点击右侧扳手图标编辑
   - 开启“无限额度”、“永不过期”

## 使用方法

### 基本生成流程

1. **填写提示词**：在提示词文本框中输入描述（最多 2000 字符，实时显示字数统计）
2. **选择模型**：不同模型支持的分辨率和参考图数量不同
3. **设置参数**：
   - 纵横比：1:1、2:3、3:2、3:4、4:3、4:5、5:4、9:16、16:9、21:9
   - 分辨率：根据模型自动切换可用选项
4. **添加参考图**（可选）：
   - 点击“添加图片”选择参考图
   - 点击图片右上角 × 删除单张
   - 点击“清空全部”一键清除
5. **生成图片**：点击“生成图片”按钮
6. **保存结果**：
   - 点击“保存图片”导出（自动生成带时间戳和模型信息的文件名）
   - 点击“保存原始JSON”导出完整响应
   - 点击“复制图片”复制到系统剪贴板

### 生成前参数确认

该功能默认开启，每次生成前会随机抽查模型、纵横比、分辨率参数之一，需要选择正确选项才能继续，否则会拒绝生成，并提醒你修改参数。如果这些参数没有更改过，那么弹窗不会出现，减少打扰，直到参数被更改。

- 该功能可以在“生成图片”按钮上方的“**生成前确认**”复选框处关闭。

### 日志功能

启用“保存日志到文件”后，所有操作会记录在 `logs/` 目录：

- **日志命名规则**：按模型区分（如 `Gemini-3.1_20260510_143022_success.log` 或 `GPT-image-2_20260510_143022_error.log`）
- **日志内容**：JSON 格式，包含时间戳、模型、提示词、参数、响应数据等完整信息
- **图片提取工具**：启用日志时自动生成 `export_images_from_log（从Log中提取图片）.py`，双击运行可从日志文件中提取并保存图片
- **安全保护**：API Key 在日志中已自动脱敏为 `SK_HIDDEN_API_KEY`

## 注意事项

⚠️ **重要提示**

- 大分辨率图片（2K/4K）生成时间较长，建议设置充足的超时时间，但一般不会超过24小时
- GPT Image 2 VIP 模型的参考图虽然设置了上限为 10 张，但实际上超过5张可能会导致模型忽略部分图片
- 日志文件可能包含提示词内容，请妥善保管 `logs/` 目录
- 缩放功能在最大化状态下切换，可能会暂时恢复普通窗口
- 参考图总大小会影响请求速度和成功率，建议控制图片数量和尺寸
- macOS/Linux 平台复制图片功能需依赖系统命令（osascript / xclip / wl-copy），如无法复制请检查相应工具是否安装
- 生成失败时，请检查“原始响应”标签页中的 `finishReason` 和 `safetyRatings` 信息。或留意弹窗

## 故障排除

**图片生成失败**

1. 检查 API 密钥是否正确，是否余额耗尽
2. 确认提示词未触发安全过滤器（查看 `safetyRatings`或者弹窗）
3. 查看“原始响应”标签页的 `finishReason` 错误信息
4. 尝试切换其他模型生成
5. 检查网络超时设置是否过短
6. 如开启系统代理，请确认网络稳定或关闭代理重试

**界面显示异常**

1. 重置缩放至 100%
2. 用鼠标拖动调整粉色的分隔条
3. 确保所有依赖已正确安装
4. 重启程序恢复默认状态

**无法复制图片**

- Windows：确保 `pywin32` 已安装（`pip install pywin32`），否则仅支持 BMP 格式
- macOS：需要系统支持 `osascript` 命令
- Linux：X11 需要 `xclip`，Wayland 需要 `wl-copy`
- 如仍失败，可手动保存图片后在系统内复制

**依赖安装失败**

- Windows：使用 `pip install --user` 安装到用户目录
- Linux/macOS：使用 `pip3 install --user` 安装，或视情况选择正确的安装方法
- 检查 Python 环境是否正常，`pip` 是否已添加到系统变量（未添加`pip`会导致无法自动安装依赖，推荐重装python）
